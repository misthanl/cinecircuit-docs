## CineCircuit 可以做什么

| 功能 | 能解决的问题 | 主要入口 |
| --- | --- | --- |
| 影视发现 | 查看影视资料，按电影或电视剧寻找目标 | 探索、顶部搜索框 |
| 资源搜索 | 从已配置的来源中寻找可获取资源 | 搜索结果 |
| 自动订阅 | 按规则持续寻找电影或缺失剧集 | 订阅 |
| 站点连接 | 保存站点认证、RSS、优先级和下载器选择 | 站点 |
| 下载管理 | 对接下载器，查看下载及网盘离线任务 | 下载器、下载任务 |
| 多存储管理 | 连接本地目录及网盘，浏览和管理文件 | 存储、文件管理 |
| 媒体整理 | 识别影视、重命名、分类、处理整理失败记录 | 媒体整理、设置 → 整理 |
| 元数据 | 生成 NFO、海报、背景图等媒体库资料 | 设置 → 刮削 |
| STRM 同步 | 将网盘媒体映射为本地可入库的播放链接文件 | 存储 → 同步设置 |
| 播放接入 | 解析播放地址、对接媒体服务器、配置用户播放策略 | 媒体服务器、直链缓存 |
| 扩展与维护 | 安装独立插件、查看日志和服务状态、发送通知 | 插件库、设置、顶部快捷入口 |

## 两种常见用法

### 已有网盘媒体，想在电视上看

连接存储 → 选择网盘媒体目录 → 生成本地 STRM → 让媒体服务器扫描 → 在客户端播放。

不需要先配置自动订阅，也不要求把所有原视频下载到 NAS。STRM 文件保存的是播放地址；实际播放是否经过服务器中转，取决于网盘与播放模式。

### 想自动获取并整理新内容

配置资源来源 → 添加订阅和筛选规则 → 下载或转存 → 整理到媒体目录 → 同步 STRM / 元数据 → 刷新媒体服务器。

## 支持范围怎样理解

- 存储接入包含 115、123、光鸭、夸克等；不同提供方及登录方式可用的上传、分享转存、离线、同步和播放能力不同。
- 下载器提供 qBittorrent、Transmission 接入；媒体服务器包含 Emby、Jellyfin、Plex 接入。具体配置项以添加菜单和编辑页面为准。
- 插件用于扩展独立功能。安装插件后，需要按插件说明完成配置、授权和启用。
- 站点或网盘出现于菜单，表示应用有对应接入实现；实际可用性仍取决于账号权限、网络和第三方接口。

## 几个常见名词

| 名词 | 通俗解释 |
| --- | --- |
| 刮削 | 根据影视身份获取标题、简介、演员、海报等信息 |
| NFO | 保存影视信息的本地文件，供媒体服务器读取 |
| STRM | 保存播放 URL 的小文本文件，本身不包含视频 |
| 整理 | 对原始媒体执行识别、分类、命名和文件操作 |
| 同步 | 按目录映射生成或更新本地 STRM，按配置处理元数据 |
| 302 | 把播放器引导到另一个播放地址的 HTTP 跳转 |
| 播放池 | 将可参与播放的账号组织起来，供播放策略选择；仅在支持时配置 |
