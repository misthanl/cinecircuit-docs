# 插件与运行管理

[返回首页](../README.md)

## 1. 安装与启用插件

打开“**插件库**”，通过插件列表、仓库源或离线 ZIP 安装需要的插件。

1. 选择插件，查看名称、版本和说明。
2. 按界面完成安装确认。
3. 到“**已安装**”填写插件配置。
4. 点击启用，检查申请的权限并完成确认。
5. 如插件提供定时任务，配置时间并保存。
6. 从运行记录确认首次执行结果。

安装完成不等于已经启用。插件页面入口还可能受插件自己的菜单显示开关控制。

第三方插件会在服务器中执行代码，安装来源需要可信；界面权限清单不意味着插件在独立沙箱中运行。

### 仓库源与离线安装

仓库源入口支持 `owner/repository`、GitHub 仓库地址或相应 `plugins.json` 地址。需要填写实际可访问、包含插件发布索引的来源，普通文档仓库不能作为插件源。

离线安装使用符合应用插件规范的 ZIP 包，不是任意源码目录的压缩包。插件库为空时，检查可用离线目录、远程来源和访问权限。

## 2. 配置通知

打开“**设置 → 通知**”：

1. 选择可用的通知渠道。
2. 填写该渠道要求的凭据、目标等信息。
3. 选择需要通知的事件，按需配置模板和发送时间窗口。
4. 保存配置；页面提供测试操作时，先发一条测试消息。

任务执行成功但没有通知时，检查渠道启用状态、事件选择、时间窗口，以及接收目标是否正确。

## 3. 在哪里看运行状态

| 入口 | 适合查看 |
| --- | --- |
| 仪表盘 | 应用总体情况 |
| 下载任务 | 下载、离线等任务进度 |
| 媒体整理 | 识别、整理结果和失败详情 |
| 直链缓存 | 播放地址缓存相关状态 |
| 顶部快捷入口 → 健康检测 | 连接、目录权限与核心配置 |
| 顶部快捷入口 → 网络检查 | 外部服务的连通性 |
| 顶部快捷入口 → 日志 | 错误、处理过程和最近运行信息 |
| 服务入口 | 定时服务的状态、执行时间和最近结果 |
| 插件运行记录 | 插件单次运行结果和权限审计 |

排查时记录具体时间、任务名称和出错阶段。只有“不能用”的描述很难定位问题。

## 4. 备份与更新

更新前备份整个配置目录，并保留可回退的镜像版本。数据库一致性备份可以在停止应用后复制配置目录完成。

示例仅适用于本章所用的 Linux 目录布局：

```bash
# 在保存 docker-compose.yml 的部署目录执行
docker compose stop cinecircuit
tar -czf "config-backup-$(date +%Y%m%d-%H%M%S).tar.gz" config
docker compose start cinecircuit
```

确认备份成功后，在合适的维护时间更新：

```bash
docker compose pull
docker compose up -d
docker compose ps
docker compose logs --tail=100 cinecircuit
```

更新后检查登录、存储目录、一次同步和一次播放。镜像回退不一定兼容更新后的数据库；恢复时应使用相匹配的配置备份。

### 插件数据在哪里

应用配置在 `/config`。独立插件运行代码默认在 `/app/plugin-runtime/installed`，镜像提供的安装包目录在 `/app/plugin-runtime/catalog`。

重启和删除重建容器不同。容器重建后，插件恢复依赖镜像目录或已记录来源中可取得的相同版本安装包；不要认为只备份 `/config` 就包含了所有插件代码。保留需要的准确版本安装包和来源信息。
