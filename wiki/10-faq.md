# 常见问题

[返回首页](../README.md)

## 页面打不开

1. 执行 `docker compose ps`，检查容器是否运行或反复重启。
2. 查看 `docker compose logs --tail=100 cinecircuit`。
3. 核对访问地址、`PORT`、宿主机防火墙和网络模式。
4. host 网络下直接访问宿主机监听端口；不要只调整 `ports` 而忽略 `PORT`。

## 找不到初始化令牌

查看首次启动日志。若日志已被截断，可查看更早的容器日志。已经创建管理员后，初始化流程不再适用，不应通过删除配置目录来找回登录入口。

## 网盘保存了，但显示待绑定

保存实例和完成账号认证是两个步骤。重新打开“账号设置”，完成登录/扫码，确认账号信息。二维码过期就重新生成。已有授权失效时重新授权，并检查网络。

## 为什么看不到本地目录

应用读取的是容器路径。宿主机存在目录，但未挂载给容器，应用就看不到。检查媒体挂载、已启用的本地存储及权限；不要把 Windows 路径或宿主机路径直接填入 Linux 容器的目录字段。

## 能搜到影视资料，却没有下载资源

影视资料和资源来源分开配置。检查站点/获取源是否启用、认证是否有效、资源是否被规则过滤。先用一个来源和宽松规则测试，再逐步收紧条件。

## 订阅一直没有动作

检查订阅是否暂停、来源是否启用、站点搜索范围、规则组、目标下载器或网盘目录。电视剧还需核对季与缺失集数。到订阅历史、任务页和日志确认具体停在哪个阶段。

## 下载完成，但没有整理

检查下载完成后的处理配置与整理开关；核对下载器报告路径是否能被 CineCircuit 找到。网盘转存目录必须匹配整理来源。查看“媒体整理”的失败记录，而不是仅看下载器中的完成状态。

## 有文件，但没生成 STRM

按顺序检查：

1. 网盘文件位于同步映射覆盖的目录中。
2. 同步来源选的是媒体文件所在目录。
3. STRM 输出路径已挂载且可写。
4. 手动全量同步确实执行完成。
5. 文件扩展名和过滤设置允许该文件被处理。

只打开“自动整理”，不代表已经配置或执行 STRM 同步。

## STRM 已存在，但媒体服务器不显示

媒体服务器必须能看到同一份输出文件。检查它的目录挂载和媒体库路径，执行扫描；必要时检查媒体类型、命名和 NFO。CineCircuit 中生成成功，不代表另一容器已经能读取。

## 媒体显示了，但无法播放

| 现象 | 优先检查 |
| --- | --- |
| 连接超时 | STRM 内地址是否可达，域名、端口、协议是否正确 |
| 内网能看、外网不行 | STRM 或客户端入口是否仍是仅内网可达地址 |
| 提示拒绝或无权限 | 匿名策略、用户路由、媒体服务器默认策略 |
| 提示账号或授权失效 | 网盘账号授权；夸克 TV 授权是否过期 |
| 个别媒体失败 | 原文件是否存在，识别映射是否正确，是否缺少目标副本 |
| 更换域名后失败 | STRM 是否仍保存旧地址，重新同步时是否跳过已有文件 |

先验证单账号默认播放，再逐步加入反代、播放池和用户独立策略，便于定位故障。

## 为什么网盘 A 有某个开关，网盘 B 没有

自动化和播放功能按网盘能力展示。例如生活事件属于 115 能力，夸克没有离线下载和播放池入口。按钮缺失不一定是安装失败。

## 插件装好了，却没有运行

到“已安装”检查启用状态、权限、必填配置、定时任务及运行记录。插件自带的菜单显示开关可能单独控制入口。容器重建后还应检查对应版本安装包是否能恢复。

## 如何提供有效的问题反馈

请描述：

- 使用的镜像标签、版本与部署方式。
- 操作入口、执行步骤和预期结果。
- 实际错误、出现时间、相关任务状态。
- 去除凭据的日志片段或截图。

不要提交真实配置目录、数据库、账号密码、Cookie、API Key、完整私有 RSS 或带签名的播放链接。
