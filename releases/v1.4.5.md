# v1.4.5 · 完善助手连续操作与整理同步

## 新增

- 新增猪猪、高清视界站点 Token API 支持，可检查连接、搜索资源并提交下载。

## 优化

- 减少订阅搜索、批量整理和刮削交接中的重复查询与入队操作。
- 助手与更新记录入口支持工作区切换，关闭更新记录时保留助手会话。
- 完善外挂字幕的语言和标题命名，方便媒体服务器识别显示。

## 修复

- 修复文件已上传到网盘后，整理记录或后续同步未完整保留的问题，并补齐中断后的恢复。
- 修复批量手动整理时文件明细缺失、任务空白和重复任务问题，手动单文件整理不再依赖下载器状态。
- 修复自动整理和同步中，一个通道异常影响其他独立任务，以及 STRM 写入成功被刮削交接失败误报的问题。
- 修复助手连续选择、批量下载、完成后继续和重复提交的状态承接，并正确处理订阅多次暂停与恢复。
- 修复助手操作结果查询中的完成状态误判、旧失败结果混入重试结果，以及整理失败记录预览不准确的问题。
- 修复副本任务并发创建和准备阶段失败后的重试问题，避免重复外部传输。
- 修复插件页面中较慢的请求被提前中断的问题，保留上传和自定义请求的超时设置。
