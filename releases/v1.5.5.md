# v1.5.5 · 消息用户绑定、接收范围与界面一致性优化

## 新增

- 用户设置支持绑定企业微信 User ID 和 Telegram User ID，通知菜单及助手按绑定用户执行操作，并遵循用户权限和订阅归属；所有用户均未绑定时沿用管理员使用方式。
- 通知设置支持按消息类型选择所属用户、管理员、所属用户及管理员或全员作为接收范围。
- 飞牛影视支持媒体库封面的读取与上传，可用于媒体库视觉封面生成和历史封面重新应用。

## 优化

- 统一横向菜单、分段切换、悬停反馈和保存按钮间距，改善设置、存储、日志及订阅详情的一致性。
- 通知时间采用滚轮选择，弹层与输入框等宽，优化手机操作和透明主题下的可读性。
- 媒体库视觉封面优化动态封面的图片兼容与标题显示，统一配置和历史封面页面的表单及边框样式。

## 修复

- 修复手机日志弹窗中任务与明细切换被裁切、时间弹层导致输入框移位及点击时键盘闪现的问题。
- 修复推荐媒体图片切换时旧图片覆盖当前内容的问题。

## 升级提示

- 本次不支持从 v1.5.4 热更新：基础运行环境、依赖或数据库代码指纹变化；离线插件目录变化，需要基础镜像；镜像构建规则变化。请拉取新镜像并重建容器，保留原有数据挂载。
