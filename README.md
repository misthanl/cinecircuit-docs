# CineCircuit 使用指南

**从连接网盘到自动入库，一步步搭建自己的媒体工作流。**

CineCircuit 是面向自建媒体库的自动化管理工具，将影视发现、资源订阅、下载与转存、媒体整理、元数据生成、STRM 同步和播放服务连接起来。

## 第一次使用，建议走这条路线

1. 部署应用，创建管理员。
2. 配好刮削服务和 STRM 直连地址。
3. 连接一个存储账号，确认可以浏览目录。
4. 选择少量有权使用的媒体文件，跑通整理、同步和播放。
5. 再连接资源来源与下载器，开启自动订阅。

已有网盘媒体库的用户，可以先跳过站点、下载器与订阅配置，直接阅读存储、同步和播放章节。
